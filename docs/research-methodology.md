# 立委事件資料研究規範

## 公開分類

- **立法與問政成果**：必須有具體提案、質詢或協調行動，並記錄審查、通過與執行情形。委員會席次、出席或單純連署不列為成果。
- **公益與公共服務**：分辨本人捐贈、號召募款、企業媒合與公帑爭取，不把公共預算或他人捐款寫成委員個人捐贈。
- **爭議與責任紀錄**：分辨指控、偵查、起訴、審判、上訴及確定結果，保留當事人回應和最新程序狀態。
- **人物側寫**：只收錄能核實且具有公共意義的經歷或事件。

## 查核矩陣

每位委員都記錄完成下列五類來源的搜尋，四個公開分類逐類檢查；找不到符合門檻的內容時顯示「截至查閱日尚無已核實資料」。

1. 立法院提案、公報、議事錄與質詢影片
2. 行政機關回應、預算、決算、工程及政策執行結果
3. 法院、檢察署、監察院、審計部、中選會及政治獻金資料
4. 中央社、公視及其他具採訪制度的新聞
5. 公益受贈單位、工會、政黨及本人聲明

## 公開門檻

- 直接原始來源可單獨支持一般事件。
- 僅有新聞或本人聲明時，需另一個獨立發布者交叉核對。
- 爭議需正式紀錄，或至少兩個獨立發布者；必須附當事人回應，並避免把起訴或未確定判決描述為有罪。
- 任期前事件限公共職務、參選誠信、重大公益或公共利益相關內容，頁面另標示「任期前」。
- 同一事件的後續報導合併為同一條時間線，不重複計數。

## 欄位與顯示

每則事件保存日期、角色、任期關係、結果階段、證據強度及來源定位。來源保存首次查閱與最近複核日期。頁面每類先顯示最近三則，資料層不設筆數上限，也不計算正負分數或排名。
