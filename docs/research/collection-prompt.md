# 更新立委快照的研究指引

1. 先開啟[立法院第 11 屆現任及離職名單](https://www.ly.gov.tw/Pages/List.aspx?nodeid=109)，記錄實際查閱日期、每位姓名、名單分組及個人頁 URL。
2. 逐一開啟個人頁，核對姓名、官方選區文字、到職日期及離職生效日期。只能從網址的 `nodeid` 建立人物 ID；姓名相同時不可猜測身分。
3. 將逐頁結果更新至 `data/research/profile-capture.json`。無法開啟或欄位缺漏的頁面需要先補查，不可推測並公開。
4. 將 `scripts/build-2026-data.mjs` 中的 `asOfDate` 改成實際查閱日期，執行產生程式與 `npm run data:validate`。檢查 2026 年內離職或遞補者，並人工抽查網站欄位的來源連結。

本輪只發布姓名、選區與說明名單時點所需的任職資訊。不蒐集提案、爭議、學經歷或財務資訊。
